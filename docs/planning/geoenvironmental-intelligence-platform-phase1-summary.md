# 地缘环境智能计算平台首期改造方案

> 基础平台：NTL-GPT  
> 人工单价：420 元/人天  
> 总工作量：111 人天  
> 人工报价：46,620 元

## 一、项目目标

在现有平台基础上建设可访问、可计算、可扩展的地缘环境智能计算平台，
形成地缘态势展示、冲突专题分析、多源数据计算、企业知识检索和国家画像能力。

## 五、首期验收结果

1. 平台完成从夜间灯光专业系统向地缘环境智能计算平台的产品和视觉转型。
2. 此前交付版本补齐近期稳定功能，并完成地缘政治多智能体架构升级。
3. 企业知识库可以安全检索，答案包含可核验来源。
4. 缅甸冲突系统完成接入，可以形成地图、时间线、分析结果和专题报告。
5. 平台具备 8–12 个稳定地缘数据接口，并保留来源、时间和许可信息。
6. 事件监测和数据获取接口完成接入周边国家地缘环境监测预警平台，并通过联调验收。
7. 完成 5–8 个试点国家的国家画像和关系知识图谱。
8. 生产服务可通过 HTTPS 访问，具备账号、日志、备份和恢复能力。

## 六、需要甲方提供

- 企业知识库 API 文档、测试账号、鉴权和权限规则；
- 缅甸冲突系统 API 或源代码、字段说明、测试数据和数据许可；
- 周边国家地缘环境监测预警平台的 API 文档、鉴权方式、测试环境、字段规范和联调联系人；
- 首批 5–8 个试点国家名单；
- 生产服务器、域名及必要的第三方服务账号。

## 七、报价说明

报价仅包含研发人工，不包含模型 API、服务器、对象存储、商业数据、
商业地图、短信邮件、安全测评和第三方服务费用。新增页面、国家、数据源或
外部系统按 420 元/人天另行评估。
