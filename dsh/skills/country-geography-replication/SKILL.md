# 国别地理分析复刻

把一份已发表分析（书、论文、报告）用它的原始数据重算一遍，并按原文的表、图、结论格式交付。
适用：人口/城市/经济/交通等统计与制图类分析。不适用：没有原始数据的纯文献综述；平台未接入的数据源
（要先说明缺口，不要用手工填数替代）。

## 一、先锁口径，再动数据

公式定义通常在**表注/图注脚注**里，其次在方法节。复刻前把每个指标写成公式，写明单位与排序规则。

- 反例：城市首位度按“第一位/第四位”算；正例（《缅甸地理》表 6-2 脚注）：`S2 = P1/P2`、
  `S4 = P1/(P2+P3+P4)`、`S11 = 2×P1/(P2+…+P11)`——S11 首位的系数是 **2**，算错就整表对不上。
- 位序类模型要写清形式与变量：位序累积规模模型 `累积人口 = a·ln(位序) + b`，`位序` 是每年**各自**降序的序号，
  不能三年共用一套排序。
- 口径写不清楚就先问用户（`ask_user_question`），不要用“常见定义”猜一个。

## 二、核对数据（写进回答，不要省）

1. 样本量与筛除规则（例：前 77 位城市）；2. 单位（万人 / 人 / km²）；3. 年份与口径来源；
4. 缺测与异常值（面积过小导致密度爆表的乡镇要**标注**，不要删）；5. 边界/网格版本（MIMU、GADM、GUB 互不通用）。

## 三、复算与对照

用 `geo_execute_python` 或注册的 GIS 工具重算；脚本、中间表、图都写进 `outputs/<作业ID>/`。
逐项与原文数值对照，结论只能落在三类之一，并写清依据：

| 对照结果 | 写法 |
| --- | --- |
| 一致 | “与原文一致（保留原文位数）” |
| 舍入差异 | “原文 1.95，本数据 1.945，属位数取舍” |
| 实质不一致 | “原文 X=1.945，本数据 X=1.651；可能原因：原文 2000 年城市人口用 LandScan+GUB 估算，与本表估计口径不同” |

**禁止**把实质不一致写成“完全复现”“全部一致”；也禁止只说“略有差异”而不给可检验的原因假设。
不确定原因时写“原因未确定，需比对原文数据来源”，不要编。

## 四、复刻原文的表与图

- 表：标题（含年份/单位）+ 每列单位 + `资料来源：` 脚注（写明原始数据与本书页）。
- 图：中文标签；坐标轴写清变量与单位（`累积人口（万人）`、`ln(位序)`）；多年份用不同标记 + 图例；
  拟合式与 R² 以文本标注在图上（例：`y=110.32ln(r)+290.61  R²=0.9889`）；图下写 `资料来源：`。
  字体设置见技能 `geospatial-visualization-cjk`。
- 保留原文的有效位数，不要为了好看少给或凑整。

## 五、结论与限制

结论段写“数据说明了什么”，限制段写“不能说明什么”：数据是估计值、样本量、时间口径、序列相关、
R² 高只说明拟合好、不证明“分布均衡”或任何因果；跨期比较要先确认两期的口径一致。

## 六、交付结构（建议）

`口径定义 → 数据与样本 → 结果表 → 图 → 与原文逐项对照 → 结论 → 限制`。
回答里给关键数字与图，明细留在 `outputs/` 的 CSV/脚本里；来源与产物路径按
`workspace-and-artifact-contract`，证据链按 `claim-evidence-chain` 落到
`geo_write_evidence`（断言必须引用真实产物或带检索时间的来源）。

## 七、常见错误

- 用“通行定义”替代原文脚注；跨年未重新排序；单位混用（万人 vs 人）；
- 把高 R² 写成“城市规模分布均衡已证明”；把估计数据写成观测值；
- 出现不一致就改口径直到对上——那是调参，不是复刻；
- 只给结论不给表和图，或图没有单位与来源。
