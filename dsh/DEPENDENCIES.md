## 0.1.2 线 AgentTeams fork 的针对性改动（历史记录，0.1.5 不再适用）

这些约束当时靠改动 fork 实现；0.1.5 线把它们移到 DSH 原生平面（原生预设 + 原生 subagent
注册表 + platform 的方案审批与角色绑定），下表只作为迁移对照保留：

- 名字与配置由服务器控制，成员不能选择模型、提供执行 persona 或横向委派。
- 多步研究强制暂存；用户通过授权 API 批准具体方案版本。模型不能自批。
- 已批准后不能无确认扩充范围或成员；主管不能抢占专员任务。
- 成员只保留角色工具、认领、任务回报、状态与向主管汇报功能。
- 单独保留父子会话归属，用于归档后的完整历史和流式角色标识。
- 关闭其通用 Web 操作面，所有产品操作经过 platform 的账号与项目授权。
- 修复构建脚本的 Windows 路径校验，保留上游许可证与生命周期回归测试。

当年的独立源码差异保存在 `dsh/vendor/agentteams-geosentinel.patch`，**该文件已随
`dsh/vendor/` 一起删除**（需要时从 git 历史取回）；它从未发布到上游 npm，也没有改写用户
原有的个人插件缓存。
