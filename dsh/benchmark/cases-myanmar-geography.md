## 0. 读取方式与引用限制

- 该书 PDF 是 **379 页纯扫描件**（Fuji Xerox D110，无文字层）。本轮用本机 RapidOCR 逐页识别，
  文本缓存在 `dsh/.runtime/myanmar-ocr/pNNN.txt`。
- **PDF 页 = 印刷页 + 16**（已用页眉页码核验：印刷 78/79/80 ↔ PDF 94/95/96；印刷 168/169/170 ↔ PDF 184/185/186）。
- 重点章节页码：第四章 缅甸人口 = 印刷 81–131（PDF 97–147）；第六章 城市地理 = 印刷 171–202（PDF 187–218）。
- **限制**：OCR 对数字与专名仍会出错（例如“缅昂/洞鸽”之类地名）。任何要写进用例期望值的书本数字，
  必须先人工对照原页；下面的“书中数值”均来自 OCR，仅作为候选用例的线索，不作为已核实结论。

## 2. 建议案例（A 组：能用文件夹里的数据核对书本数值）

判定方式建议统一为 **数值容差 + 关键词 + 必过项“是否说明数据限制”**。

### M1 城市位序累积规模模型复算（图 6-2）
- 书中给出三条拟合式：2000 年 `y = 110.32x + 290.61, R² = 0.9889`；2010 年 `y = 213.53x + 280.45, R² = 0.9826`；2019 年 `y = 208.38x + 520.43, R² = 0.9911`（OCR 读数，需复核）。
- 数据：`城市体系位序规模.xlsx`（77 城，pop2000/2010/2019）。
- 做法：对三个年份分别拟合并报出斜率、截距、R²，与书中数值对比；说明样本为前 77 位城市、年度口径来自普查/估计。
- 判定：拟合结果数值容差（±1%）+ R² + 显式说明“数据为城市人口估计值，非平台观测”。
- 展示能力：真实数据回归、产物落地（表 + 图）、结论可核对。

### M2 城市首位度（表 6-2）
- 书中：2000 年 S2=2.422、S4=1.945、S11=1.927；2010 年 3.418/2.204/2.283；2019 年 2.947/2.199/2.599（OCR 读数，需复核）。
- 数据同上。做法：S2/S4/S11 定义核算（首位城市人口 / 第 2、4、11 位城市人口），并解释为何 2010→2019 首位度回落。
- 判定：三个年份 9 个数值容差 + “首位度=人口比值、不是集中度指数”的口径说明。
- 展示能力：定义敏感的指标核算（容易算错口径）。

### M3 城市人口规模等级结构（表 6-4）
- 书中：6 级（≥10 万 / 5–10 万 / 2–5 万 / 1–2 万 / 0.5–1 万 / <0.5 万），1993 年 14/19/81/74/71/53，2014 年 18/34/…（OCR 不全）。
- 数据：位序表有 2000/2010/2019，**没有 1993**，只能复算 2019（或 2000/2010）等级分布。
- 判定：分级计数 + 明确写出“1993 年数据不在本次输入中，故不做跨年对比”——**这是一条很好的“如实报告缺口”用例**。

### M4 省邦人口密度空间格局（图 4-16）
- 书中把 1973/1983/2014 人口密度分为 8–25 / 26–50 / 51–100 / 101–200 / 201–400 / 401–700 等档，并给出“中部高、东西低”的结论。
- 数据：三个年份的省邦密度 CSV + MIMU ADM1 边界（官方口径）+ 乡镇图层。
- 做法：按书中阈值分级制图，给出各省邦密度表与全国均值、最高/最低省邦；比较 1973→2014 的增幅。
- 判定：分级正确 + 省邦排序（仰光/曼德勒/内比都领先）+ 边界来源写明（MIMU vs GADM）。

### M5 年龄结构与老龄化指数（表 4-8、图 4-18/4-19）
- 数据：`2019-2020年缅甸年龄人口分布.xlsx`（0–14 / 15–64 / 65+，万人）、`老龄化指数分布.xlsx`、`性别比分布.xlsx`。
- 做法：核算老少比（65+/0–14）、抚养比、性别比，并复算书中的全国值（如 0–14 岁 1479.4 万、15–64 岁 3624.7 万、65+ 353.8 万，OCR 读数）。
- 判定：派生指标定义正确 + 数值容差 + 单位（万人）。

### M6 净迁移率与人口增长的空间对照（图 4-25/4-26）
- 数据：`2009-2014年缅甸国内人口净迁移率（每千人）.xlsx`（合计/男/女）+ `缅甸2019-2020年人口增长率各省分布.xlsx`。
- 做法：省邦级散点与相关系数，检验“净迁入省邦是否增长率更高”；分别报告合计与男女差异（书中提到克钦邦与德林达依省男女净迁移率相差约 16 个百分点）。
- 判定：相关系数 + **必过项：说明两段时间不重合，相关不等于因果**。

### M7 城镇化与经济结构（WDI.xlsx）
- 数据：`lurb, lgdppc, lnagr`（2000 年起，均为对数值）。
- 做法：复现“城镇化率—人均 GDP—农业占比”的统计关系，报出系数与 R²，并说明样本量与序列相关性限制。
- 判定：回归结果 + “对数值不能反推原值精度”的限制说明。

### M8 国际移民目的地结构（图 4-27/4-29）
- 数据：`移民国外分布.csv`（省邦—区—近期移民数）。
- 做法：按省邦汇总、排序、算占比，给出前 5 位来源区与集中度；与书中“按目的地国划分”的图对照时明确本数据只有来源侧、没有目的地国字段。
- 判定：汇总正确 + **显式指出“输入不含目的地国，故不能复现目的地结构”**。

### M9 乡镇密度异常值审查（数据质量用例）
- 数据：`Export_Output.shp`。实测 `Pop_Den1` 分布：中位数 107.5，最大 **53,930.2**；`Area_SqKm` 最小 **0.60 km²**。
- 做法：审查极端值来源（面积过小的多边形、飞地、行政区拼接），给出处理方案（阈值/标注/不剔除）与影响。
- 判定：**必过项“未擅自删除异常值，而是标注并说明影响”**；这条最能区分“会算”与“会做研究”。

### M10 仰光城市扩张（图 6-3、表 6-3）
- 书中：1990→2000 建成区 161→289 km²（+79.5%），2010 年 329 km²，2010→2020 +124.6%；四个主要城市 2020 年面积与扩张类型（仰光 452.27 km² 外延型、内比都 92.85 km² 卫星城型等，OCR 读数）。
- 数据缺口：**建成区/Global Urban Boundary 数据不在文件夹里**（书中 p192 明确用了 GUB 与 GEE）。
- 两个选项：(a) 用平台 GEE 能力取 GUB/GHSL 建成区数据复算；(b) 用 VIIRS 年度夜光做“城市扩张代理”，但必须声明与建成区口径不同、不能直接与书中 km² 对比。
