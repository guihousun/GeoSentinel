# 全球事件监测

> 该功能原称「公共监测」，2026-09-10 起界面统一为「全球事件监测」（内部标识仍为 `geosentinel:monitor`、`/geo/api/monitor/*`）。改的是名称，采集、来源与权限边界不变。

## 运行结构

- `monitoring/worker.mjs` 是独立 Node 进程，不创建研究项目或智能体对话。
- 固定 Docker 入口 `monitoring/collect.py` 复用仓库原有 `monitoring/sources.py`。只挂载采集代码，不挂载用户工作区、Docker socket 或 GEE 凭据。
- 采集结果写入独立的 `snapshot.json`，原子替换并维护心跳、去重和过期状态；不进入 PostgreSQL 或账号 SQLite。
- `/geo/api/monitor/events` 与 `/geo/api/monitor/status` 是只读公共接口。所有账号和会话看到同一快照；原生监测标签每 60 秒刷新快照，不触发新的采集或模型调用。
- `/geo/api/monitor/report?eventId=...` 需要登录，按所选记录返回 Markdown 结构化简报附件；内容只来自快照字段，不触发新的采集或模型调用。
- DSH 启动时默认拉起监测进程，同目录 PID 锁避免重复运行。独立进程存续期间，研究任务的创建、取消和退出登录均不影响监测。

默认位置为 `<DSH_HOME>/monitor`，可由 `GEO_MONITOR_DIR` 指定。默认每 30 分钟采集，范围可设为 5-360 分钟；最多保留 200 条近 7 天观察到的记录。按来源事件标识去重，不声称实现跨来源的事件语义合并。

## 界面含义

- **全球地图**：同一监测快照中具有有效经纬度的记录；默认全球概览。悬停节点查看标题，点击地球图标恢复全球范围。没有坐标的新闻保留在队列，不猜测地理位置。
- **分级显示**：点符号按关注等级分为四级，等级只复述来源字段，不是影响或置信度评估：
  | 等级 | 符号 | 含义 |
  | --- | --- | --- |
  | 重点线索 | 最大实心点 + 呼吸光环 + 常显地点标签（全屏） | 来源标记为高关注，且发布于 72 小时内 |
  | 高关注 | 中等实心点 | 来源标记为高关注，发布时间较早 |
  | 中关注 | 小实心点 | 来源标记为中关注 |
  | 低关注 | 最小半透明点 | 来源标记为低关注，多为背景线索 |

  颜色仍表示事件类别（地震/野火/冲突…），大小与光环表示关注等级；等级规则写在地图上方说明行，快照也随每次请求下发 `level` 字段（`monitoring/snapshot.mjs` 的 `monitorLevel`）。缺少发布时间的高关注条目不会被升级为重点线索，因为新近程度无法证明。
- **筛选**：图例按事件类型着色并显示该类记录数，点击隐藏或恢复；「关注等级」与「时间窗」（24 小时 / 72 小时 / 7 天 / 全部）与图例一起作用于地图和列表。筛选只影响显示，不改变快照或采集。紧凑视图默认显示重点线索、高关注与中关注，低关注需要显式打开。
- **全屏视图**：工具栏「全屏查看」把面板展开为整屏研究工作台（`Esc` 或「退出全屏」返回）：左侧为可缩放地图，右侧为研究栏——研究口径与快照（快照时间、采集进程、刷新间隔、条数上限）、重点线索列表（点击定位并打开气泡）、选中线索详情（概要/要点/关注点/待核实/坐标/来源链接/带入研究对话）与来源渠道状态。进入全屏会把默认等级筛选扩到四级一次，便于总览；用户手动调整过的筛选不会被覆盖。地图左下角显示光标经纬度。
- **事件队列**：显示中文标题、来源、来源时间、地点、类型徽标、关注级别和来源链接。关注级别不是预测结果或经过研究确认的影响程度。旧独立工作台的分类筛选和详情面板已移除。
- **结构化简报**：每条记录在整理成功后展示概要、已记录要点、关注点和待核实四项；侧栏「监测简报」标签集中查看全部简报，「下载 Markdown」导出同一内容的文件。简报只复述来源字段能支持的内容，缺失项写“来源未说明”，不是独立核实结论。
- **空间数据**：侧栏「空间数据」标签列出当前对话工作区与项目上传（`inputs/`）内的可预览文件，点击后在世界底图上绘制：

  | 类型 | 预览方式 |
  | --- | --- |
  | `.geojson` / 含几何的 `.json` | 点、线、面绘制，并给出要素数、几何类型、范围与属性表 |
  | `.csv` | 自动识别经纬度列（lon/lng/longitude/x 与 lat/latitude/y）后绘制点 |
  | `.shp` | 读取 shp 几何（点/线/面/多点）与同名 `.dbf` 属性；`.shx/.dbf/.prj` 等配套文件默认不单独列出，下载 `.shp` 时自动打包为同名 zip |
  | `.tif` / `.tiff` | 解析 GeoTIFF 标签（含 BigTIFF、条带与瓦片、未压缩与 DEFLATE、单波段浮点/整型），按 2%–98% 分位拉伸渲染 PNG 预览，并给出波段、数据类型、压缩、CRS、取值范围与范围框 |

  畸形几何会被丢弃并计数，不会让整幅图空白；不含 GeoJSON 几何的 JSON 只显示字段名；LZW/JPEG 压缩、多波段或超过 400 万像元的栅格只给出元数据与范围，并写明原因。预览只读取文件，不修改产物。
- **带入研究对话**：只有用户点击后，才把所选记录保存为当前项目的私有 JSON 证据文件，并预填研究问题；仍需用户点击发送，不会自动运行主智能体。
- **来源与同步**：工具栏右侧显示可见/全部记录数与有坐标记录数（全屏显示快照时间、渠道数与重点线索数）；「数据源渠道」按渠道显示本轮记录数或状态（本轮不可用、已限流、未启用、降级），悬停查看渠道说明。失败时保留最近的有效记录，不用演示数据填补。

## 来源与中文整理

当前启用的采集渠道：GDACS（全球灾害预警与协调系统）、NASA EONET（自然事件观测目录）、EMSC（欧洲-地中海地震中心，全球近实时地震目录）与国际新闻（13 个公开 RSS：联合国新闻、半岛电视台、BBC World、自由欧洲电台/自由电台、德国之声、Times of Israel、Anadolu、TASS、Nikkei Asia、SCMP、CNA、Africanews、国际危机组织）。ACLED 需要访问令牌，默认未启用；GDELT 受公共限流影响，本轮常显示「已限流」。

国际新闻渠道只做地缘政治与灾害相关的线索筛选：标题命中冲突、制裁、军事、外交、抗议、人道、地震洪水等词才收录；仅命中选举、议会、峰会、谈判等政治进程词时，需要同时命中两个才收录，避免把体育、经济与文娱新闻塞进队列。各源按轮转取条（每源默认 2 条、合计默认 20 条），避免单一高产媒体占满渠道。新闻条目没有坐标，只进入列表与简报，不按发布机构所在国猜事件位置。

渠道刻意包含不同立场的媒体（含国家背景媒体如 TASS、Anadolu）。每条记录都写明来源；同一事实在不同来源中的表述可能不同，简报只复述来源字段并标注待核实，不作为事实认定。

2026-09-09 在本机 Docker 采集入口实测：GDACS、NASA EONET、EMSC 三源各返回 10–12 条真实记录并带坐标，国际新闻 13/13 个源可用、返回 20 条线索；ACLED 未启用，GDELT 限流。不能据此宣称覆盖了全球全部冲突或所有来源都稳定可用。

曾评估但未纳入的渠道，保留记录以避免重复试错：

- USGS 地震目录：本机 Docker 解析 `earthquake.usgs.gov` 只得到 CloudFront IPv6 地址，直连和代理均出现 TLS 握手中断，无法采集。
- ReliefWeb 灾害条目：v1 接口已下线（HTTP 410），v2 要求申请专用 `appname`（HTTP 403），在获得授权前不可用。
- UCDP GED：公共接口现在要求 `x-ucdp-access-token`（HTTP 401）；ACLED 同样需要账号令牌（HTTP 403）。两者在获得许可与令牌前不启用。

中文整理独立调用配置的 DeepSeek 模型，每条记录只允许返回展示标题、地点和结构化简报；不授予工具权限，不接受新事件 ID，不允许改坐标、来源链接或严重性。原题始终保留，模型生成的中文也不是人工逐条核验后的事实。此轻量请求关闭思考模式以避免输出预算耗尽；参数依据 [DeepSeek 官方说明](https://api-docs.deepseek.com/guides/thinking_mode/)。

整理按每批 40 条分批请求，避免长批次被截断；结果按「标题+摘要+地点」指纹缓存，字段未变时不重复调用模型。每轮先合并快照再整理整份保留集合，因此上一轮遗留、尚未生成简报的记录也会补上，不只处理本轮新候选。采集轮失败时 2 分钟后重试（不超过正常间隔），避免一次瞬时失败让共享地图陈旧整个周期。无凭据、翻译失败或停用翻译时，用中文事件类型加原始专名降级展示，不阻断采集。新闻发布机构所在国不会被当成事件发生国。

## 免费地图与离线部署

最终采用随项目依赖部署的 Natural Earth / world-atlas 概览边界，由 Leaflet 展示，不需要地图 API Key 或外部瓦片请求。Natural Earth 数据为公有领域，可用于个人、教育和商业用途，具体参见 [官方使用条款](https://www.naturalearthdata.com/about/terms-of-use/)。依赖许可证仍应随各自软件包保留。

这是 1:110 million 小比例尺世界概览，不是 110 米分辨率数据。边界仅用于定位背景，不能替代精确行政区数据或作为争议边界认定依据。渲染使用经度连续化及 geojson-vt 裁切，避免跨日期变更线的连线贯穿地图。

曾测试的在线底图在本机出现 API Key 提示或网络超时，因此当前默认不依赖它们。免费世界底图不代表采集网络、服务器或中文整理模型调用没有运行费用。

## 配置与管理

配置在 `dsh/.env`，无需修改个人 DSH 配置或原 Conda 环境：

- `GEO_MONITOR_ENABLED=false`：不自动启动监测。
- `GEO_MONITOR_INTERVAL_MINUTES=30`：采集间隔。
- `GEO_MONITOR_TRANSLATE=false`：停用模型中文整理。
- `GEO_MONITOR_MODEL`：管理员指定翻译模型。
- `GEO_MONITOR_PROXY`：采集容器代理；未设置时可沿用 `GEO_GEE_PROXY`。不影响用户分析容器的禁网策略。
- `GEO_MONITOR_EXTERNAL=true`：DSH 只读共享快照，由外部进程管理监测。
- `NTL_MONITOR_NEWS_ENABLED=false`：停用国际新闻渠道。
- `NTL_MONITOR_NEWS_PER_FEED`：每个新闻源最多收录条数（默认 2，上限 5）。
- `NTL_MONITOR_NEWS_MAX`：国际新闻渠道每轮总上限（默认 20，上限 40）。
- `NTL_MONITOR_NEWS_FEEDS`：自定义源，格式 `名称=URL,名称=URL`；留空使用内置 13 个公开 RSS。
- ACLED 需另外配置原有 `NTL_MONITOR_ACLED_*` 变量并确认面向用户展示的许可范围，默认关闭。

手动管理命令，均在 `dsh` 目录执行：

```powershell
node scripts/monitor.mjs --stop
node scripts/monitor.mjs
```

第一条只停止 PID 与本项目采集脚本匹配的进程；第二条前台启动独立监测。参数变化后需重新启动监测进程，仅刷新网页不会变更后台配置。若由系统服务管理，配置 `GEO_MONITOR_EXTERNAL=true`，交给该服务负责进程重启。

管理员验收可在停止已有监测后执行 `node scripts/monitor.mjs --translate-cache --once`，仅重新整理缓存；常规队列刷新不会调用该命令。停止进程不会删除原有快照，重新启动后继续使用最近的成功数据。Docker 采集入口还具有 140 秒的进程内时限。

## 验证

`pnpm test` 包含源数据归一化、结构化简报字段边界、关注等级规则（重点线索只在 72 小时内高关注成立，缺时间不升级）、报告渲染与鉴权、坏坐标、危险链接、去重、过期/失联、公共只读接口和私有导入权限测试。地图按 1366×768、1440×900 桌面视口验收；主对话输入区保持可见，地图无需外网瓦片即可渲染。
